# Current rebuild decisions

The November 7 sidebar-platform brief supersedes the earlier three-tab design,
two-miss/twin flow, original daily mix, accuracy-gated bonuses and four-round cap.
The latest explicit hosting choice is ChatGPT Sites. Namecheap supplies DNS.

- Keep the existing server, private Sites audience and D1/R2 bindings. Preserve
  existing accounts, password hashes, progress and ledger entries with additive
  migrations; never overwrite an account from demo provisioning.
- Use real /s and /t page URLs, a persistent sidebar and focused practice. Follow
  the new paper/teal/brick design tokens and local Source Serif 4/Inter fonts.
- Count each answered question once, right or wrong. Award points atomically at
  target + first-bonus, then each bonus-step; store per-date rules so later changes
  never rewrite history. Teacher settings apply tomorrow.
- Assignments and due reviews come first, then focused, weak and stretch work.
  Keep course dates and skill lists derived from the supplied plan. Future skills
  remain available for independent learning and practice.
- Queue new versions after misses at 1,3,7 days. Never repeat a served question;
  keep lesson examples separate from assessment candidates. Suspend flagged shapes.
- Generate exact numeric/fraction/coordinate/linear-expression answers. Convert
  numeric multiple-choice items to typed answers; concept choices stay at most
  one in five. No expression evaluation or floating-point grading is used.
- Paper/slide data is test input only. A number-free frame comparison supplements
  the original exact/numeric exclusion tests. Checked pools and frame evidence
  carry source hashes; builds reject stale evidence.
- Keep the old public files out of the replacement branch. Do not claim this
  erases historical Git objects or copies previously downloaded by visitors.
- Screenshot and actual-device evidence must be real. The managed browser failed
  with “the gaas-browser node_repl sandbox cannot be disabled”; do not substitute
  fabricated screenshots or claim layout, Safari or load-time verification.

## Student-facing visual revision

The user explicitly replaced the warm-paper/green textbook palette with a bright
math-workbook style: white and light graph paper, blue controls, coral geometry,
yellow points and math illustrations. Bold Inter headings replace serif headings;
MathML keeps the serif mathematics font. Existing learning and account logic stays
unchanged. SVG artwork is decorative and never represents invented student data.
